# deepsearch — fonte antes de recomendação (🟡 processo, obrigatório para frontend-engineer / backend-engineer / engineer)

- Antes de recomendar biblioteca, API ou padrão: `websearch`/`webfetch` em documentação oficial, changelog ou RFC.
- Cite URL + data da consulta no parecer. Uma afirmação sem fonte é inferência — diga isso explicitamente.
- Nunca aceite assinatura de API de memória: verifique a assinatura na fonte consultada antes de escrever código.
- Se não houver fonte disponível, declare "inferência" e proponha verificação; não apresente chute como fato.
- Esta rule é a ÚNICA descrição do protocolo. Agentes referenciam este arquivo; não o copiam.
- Nível: 🟡 processo — nenhum gate negocia por isto (`.agents/rules/gate-contract.md` §2); a cobrança é revisão de código.
