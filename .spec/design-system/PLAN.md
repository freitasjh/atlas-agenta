# Design System — baseado na Landing do Template Admin

**Fonte de verdade:** `src/pages/LandingPage.tsx`
**Tela piloto:** `src/marketing/pages.tsx`

## Objetivo
Extrair tokens + componentes reutilizáveis da landing do template admin, documentar e migrar a landing real para consumi-los.

## Componentes a extrair
- Hero (chip + headline + subheadline + CTAs + trust pills)
- SocialProof (logos)
- BentoGrid / BentoCard
- PlanosSection (título + PlanCard preview + link)
- TestimonialCard
- FaqItem (details/summary)
- CtaBanner (badge + headline + subheadline + botões)
- Footer (já em MarketingLayout)
